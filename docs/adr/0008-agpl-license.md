# The code is licensed under AGPL-3.0

The repository is public. Without a license it was "all rights reserved": readable, but nobody could legally reuse it. ULTI may become a product, so the code is licensed under the GNU AGPL-3.0. Anyone can read, run and fork it, but anyone who runs a modified version as a website must publish that version's source. That stops a closed copy from competing with ULTI. The owner holds the copyright on all of the code, so they can still relicense it later, for example to offer a commercial license.

## Consequences

- Outside contributions would be AGPL-licensed too. Accepting them without a contributor agreement would give up the option to relicense those parts.
- The bundled data and fonts keep their own licenses, which are compatible: FitnessVolt's strength standards are CC BY 4.0 (credited on the About screen) and Unbounded and Manrope are under the SIL Open Font License.

## Considered Options

- **MIT**: the simplest choice for a portfolio project, but it lets anyone host a closed copy.
- **No license, or a private repository**: keeps every right, but the public code can't be reused at all, which is the opposite of an open project.

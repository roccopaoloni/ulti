# Offline-first installable web app, not a native app

ULTI ships as an offline-first PWA rather than a native iOS/Android app. It grows by friends inviting friends, and an invite link that opens straight into the Group matters more than native polish; with a native app, every invitee would first have to install from a store, and the project would need an Apple developer account and app review. We accept that on iOS notifications only work once the app is added to the home screen, and that it feels slightly less native. Offline-first is non-negotiable because many gyms have no signal and logging must never fail mid-set.
